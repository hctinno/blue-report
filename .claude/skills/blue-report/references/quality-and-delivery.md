# 발표자료 품질과 쉬운 전달

기획과 스타일이 정리되어 제작할 때 읽는다. 회사 모양과 검사기 통과에 더해 사용 목적에 맞는 내용을 완성한다.

## 1. 내용에서 장별 구성을 결정

제공 자료를 줄여 붙이는 것으로 끝내지 않는다. 발표 후 청중이 이해하거나 결정할 사항을 중심으로 자료를 재구성한다. 주장·분석·제안을 구분하고 사용자 설명에 없는 성과·비용·일정은 만들지 않는다.

목차에는 장마다 핵심 메시지, 이를 뒷받침하는 자료, 어울리는 표현을 연결한다. 의사결정은 비교 기준과 권고 이유, 교육은 절차와 실제 사례처럼 목적에 맞는 흐름을 택한다. 제목만 읽어도 논리가 이어져야 한다.
발표 시간에 비해 장수와 설명량이 많은지 점검하고, 중복·세부 내용은 합의한 범위에서 줄이거나 부록으로 옮긴다. 출처 부족을 장식이나 추정 수치로 채우지 않는다.

한 장에는 주된 메시지 하나를 둔다. 내용이 흐름·관계·비교·일정이면 그에 맞는 도식을, 실제 정량 자료면 차트를 쓴다. 모든 장을 같은 카드 세 개나 긴 글 목록으로 반복하지 않는다. 단순한 문장에 의미 없는 도식을 붙이지도 않는다.

## 2. 실제 내용으로 대표 장과 완성본 검토

스타일 비교의 대표 내용은 에이전트가 제공 자료에서 선정한다. 긴 원문은 비교용으로 요약하고 상세 근거는 기획 기록과 본문에 보존한다. 사용자가 직접 미리보기 JSON을 작성하거나 기술적 글자 수를 맞추게 하지 않는다.
선택한 스타일의 표지·핵심 내용 장을 제작의 기준으로 삼는다. 정량 차트나 고밀도 내용이 있는 큰 덱은 어려운 대표 장도 먼저 점검해 전체에 같은 문제를 퍼뜨리지 않는다. 이미 선택·위임이 끝났으면 샘플마다 허가를 추가로 요구하지 않는다.

완성된 모든 장의 PNG 또는 해당 형식의 실제 페이지를 열어 다음을 확인한다.

| 확인 | 통과 기준 |
|---|---|
| 업무 목적과 흐름 | 장별 메시지가 목적에 연결되고 마지막에 필요한 판단·행동이 명확함 |
| 근거와 수치 | 주요 주장·수치에 출처·기준이 있고 단위·합계·비교 대상이 일치함 |
| 시각적 전달 | 주된 메시지가 먼저 보이고 정보량·글자·여백이 청중과 사용 환경에 맞음 |
| 실제 동작 | 잘림·겹침·깨진 그림이 없고 합의한 전환·효과·발표 조작이 작동함 |
| 납품 형식 | 요청한 파일이 열리고, 확인한 범위에서 편집·발표·배포 목적을 충족함 |

기술 검사 실패와 위 항목의 명백한 문제는 먼저 수정한다. 글자를 일괄 축소하거나 검사 규칙을 풀어 해결하지 않는다. 동일한 문제가 반복되면 원인을 확인하고 최대 두 번의 수정 후 남은 문제와 필요한 조건을 구체적으로 밝힌다. 서로 다른 문제까지 하나의 재시도 횟수로 묶지 않는다.
차트가 없어 검산 대상이 없다는 주의와, 글·표만 반복되거나 움직임이 과한 품질 주의를 구분한다. 후자는 내용에 맞게 고치거나 그대로 둔 이유를 설명한다.

## 3. 형식별로 검증 범위를 정직하게 전달

HTML은 내장 check_live.py와 장별 화면·발표 조작을 확인한다. PDF는 실제 생성된 PDF의 페이지를 확인한다. HTML 화면 확인만으로 PDF 완료를 주장하지 않는다.
PPTX는 내장 check_pptx.py로 압축·XML·관계 파일·슬라이드 연결·오류 텍스트를 확인한다. 가능하면 PowerPoint 또는 설치된 렌더러로 실제 장을 열고 글자·그림·편집 상태도 확인한다. 별도 스킬의 설치를 요구하지 않는다. 파일 구조 검사만 했으면 화면 배치와 편집 동작은 미확인이라고 구분한다.
환경에서 지원하지 않는 효과·렌더링이 있으면 목적을 지키는 대안을 설명한다. 사용자 요청을 묵묵히 다른 형식으로 대체하거나 확인하지 않은 기능을 완료로 표시하지 않는다.

## 4. 열고 고치기 쉬운 결과 전달

요청한 완성 파일을 먼저 링크하고 실제 미리보기를 보여준다. 근거 조사 자료나 작업 소스는 유지하되 모든 중간 파일을 사용자의 선택지로 나열하지 않는다. 원치 않은 다른 형식까지 만들지 않는다.
완료 메시지는 파일, 반영한 방향, 실제 확인 결과와 남은 제한을 간단히 담는다. HTML이면 열기·발표·다음 장의 필수 조작, PPTX면 열어 편집할 파일을 안내한다.
“3장의 비교표를 간단히”, “결론을 더 앞에”, “효과를 줄여 줘”처럼 평범한 수정 요청을 받을 수 있게 한다. 수정 시 이미 정한 목적·스타일을 유지하고 영향을 받는 장만 고쳐 다시 확인한다.
