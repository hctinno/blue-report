# 효과 라이브러리 — 요청이 있을 때 여기서 고른다

발표 덱(기준 덱 · 라이브 계통)의 애니메이션 · 효과 메뉴판이다. 효과는 이 파일 순서대로 고른다.
기준은 2026-10 사내 발표 덱 최종본이다. 그 덱의 본문 연출 63종을 **형태 · 움직임 그대로** 패턴첩
`assets/live-patterns.html`(`--deck patterns`)에 옮겼다 — 내용(조직 · 수치 · 이름)은 전부 가상이다.
연출 패턴은 패턴첩 장을 열어 보고 고르고, 단일 효과는 계통 클래스(`bl-a--*`)로 단다.

## 0. 언제 쓰나

- **기본은 부품에 든 움직임만.** 막대 성장 · 도넛 그리기 · 흐름선 · 숫자 세기처럼 부품이 저절로
  하는 움직임 외에는 효과를 덧붙이지 않는다.
- **사용자가 「애니메이션 · 효과 · 움직임을 넣어 달라」고 하면** 이 파일에서 고른다. 장마다 내용을
  보고 아래 「2. 연출 패턴」 중 맞는 것을 먼저 찾고, 없으면 「3. 단일 효과」를 조합한다.
- 효과를 새로 짤 때만 장 안 `<style data-own>` 에 `@keyframes` 를 적는다(「5」).

## 1. 원칙 — 효과는 읽는 순서를 안내한다

| 한다 | 하지 않는다 |
|---|---|
| 읽는 순서대로 하나씩 — 순번 `--i` 로 0.08초씩 | 한 장의 모든 요소가 동시에 뜨기 |
| 값은 그려지며 — 막대가 자라고 선이 그어지고 숫자가 오른다 | 값과 관계없는 회전 · 흔들림 |
| 강조는 마지막 — 강조 막대 · 도장 · 결론 띠는 `--d` 로 늦게 | 강조가 먼저 나와 나머지를 가리기 |
| 반복은 「지금 · 흐름 · 처리 중」에만 — 지금 역 맥박, 흐르는 점선 | 장식으로 계속 깜빡이는 요소 |
| 시선을 끄는 반복은 한 화면에 한 곳 | 반복 움직임 여러 개가 서로 경쟁 |
| 감속 모드에서는 처음부터 최종 모습 | 움직임에만 정보를 싣기 |

## 2. 연출 패턴 — 패턴첩에서 장째 가져온다

패턴첩 장 id 로 열어(`live-patterns.html#장id`) 넘겨 보며 움직임을 확인하고, **장을 통째로 복사**해
글 · 수치만 바꾼다. 움직임은 장에 들어 있다 — 따로 달 것이 없다. 덱 머리에
`<link rel="stylesheet" href="blue-pattern.css">` 를 더하고, 장 태그의 `xf` · `pt-이름` 클래스는 지우지 않는다.

| 연출 | 이럴 때 | 움직임 | 패턴첩 장 |
|---|---|---|---|
| 상승 곡선 표지 | 표지 · 첫인상 | 곡선이 그려지고 끝점이 달린다 · 제목 줄 페이드 | `pt-cover` |
| 장 간지 진행 | 장이 바뀔 때 | 큰 번호 · 진행 막대가 자라고 현재 장이 반짝 | `pt-chapter` · `pt-chapter-b` |
| 말풍선 → 역할 3단 | 문제 제기 → 역할 정의 | 요청 말풍선이 쌓이다 회색 · 취소선으로 걷히고, 쉐브론 3단이 들어옴 | `pt-chevron3` |
| 데이터 그리기 | 수치 비교 · 순위 · 추세 | 막대가 차례로 자라고 수치가 뒤따름 · 강조 막대는 마지막 | `pt-three-zone` · `pt-combo-chart` · `pt-gap-3panel` · `pt-segment-waterfall` · `pt-stack-compare` |
| 도넛 그리기 | 구성 · 비율 | 고리가 돌며 그려지고 가운데 합계가 뜸 | `pt-subscription` · `pt-account-mgmt` |
| 연표 · 일정 | 연혁 · 계획 · 기한 | 축이 깔리고 사건이 위아래로 떠오름 · 오늘 선 · 지금 표시 | `pt-timeline-cluster` · `pt-stage-gantt` · `pt-roadmap-gantt` · `pt-phase-years` · `pt-deadline-map` · `pt-milestones` |
| 경로 그리기 | 여정 · 로드맵 · 지금 위치 | 노선이 그려지고 역이 차례로 켜짐 · 지금 역만 맥박 | `pt-journey` · `pt-lanes3` · `pt-metro-roles` · `pt-team` · `pt-evolution` |
| 전과 후 | 지금 방식 → 바뀐 방식 | 대기열이 쌓이고 막힘 → 길이 포장되며 직접 실행 | `pt-before-after-panel` · `pt-keyin` · `pt-same-diagnosis` · `pt-scenario` |
| 흐름 · 모임 | 여러 창구 → 한 곳 → 여러 쓰임 | 점선이 흐르고 중심이 박동 · 결과가 퍼져 나감 | `pt-hub` · `pt-system-map` · `pt-api-first` · `pt-ai-draft-flow` · `pt-boundary` · `pt-verify-spread` |
| 단계 처리 | 처리 절차 · 파이프라인 | 단계 카드가 차례로 열리고 궤도 점이 돎 | `pt-process5` · `pt-steps3` · `pt-kanban5` |
| 화면 시연 | 실제 화면 위 동작 | 목록에서 파일을 고르고 열면 표시가 찍힘 · 커서 이동 | `pt-governance-b` · `pt-device-data` · `pt-app-metrics` |
| 탭 · 쪽 넘김 | 사례 여럿 · 질문 흐름 | 탭을 고르면 화면이 바뀜 · 이전 · 다음 단추로 장 안 쪽 넘김 | `pt-peer-tabs` · `pt-four-cards-b` |
| 마무리 | 결론 한 문장 | 세 아이콘이 차례로 튀어나오고 핵심 문장이 마지막 | `pt-closing` |

- 표 · 목록이 맞는 장도 패턴이 있다 — `pt-proc-table` · `pt-type-matrix` · `pt-global-sources` · `pt-milestones`. 행이 차례로 들어온다.
- 모든 패턴은 **감속 모드에서 처음부터 최종 모습**이다. 움직임에 정보를 싣지 않았다.
- 패턴 장의 단계(`data-f`)는 발표 모드에서만 접힌다. 엔진이 최종본 신호(`.on` · `.dim` · `html.anim` · `body.expand`)를 같이 단다.

## 4. 단계 전개

- 요소에 `data-f="1"` 부터. 같은 번호는 함께 열린다. 발표 모드와 펼침을 끈 상태(X)에서만 접힌다.
- 장의 노트에 `[클릭]` 을 단계 수 이상 적는다 — 대본 창 배지가 단계와 맞는다(검사기 24번).
- 장에 `data-dim` 을 달면 **지난 단계가 28% 로 흐려진다** — 지금 말하는 줄만 또렷하다(패턴 장은 `.dim`).
- 단계 안의 `bl-a` 효과는 그 단계가 열리는 순간 재생된다.

## 5. 효과를 새로 짤 때

라이브러리에 없는 연출이 꼭 필요할 때만. 장 안 `<style data-own>` 에 적는다.

```html
<style data-own>
  @media (prefers-reduced-motion: no-preference) {
    html.bl-anim #장id:not(.in) .x-node { opacity: 0 }             /* 장에 들어오기 전 */
    #장id.in .x-node { animation: xRise .6s var(--bl-ease) both;     /* 들어오면 재생 */
                       animation-delay: calc(var(--i, 0) * .08s) }
  }
  @keyframes xRise { from { opacity: 0; transform: translateY(.8rem) } to { opacity: 1; transform: none } }
</style>
```

- 감속 모드 분기 안에서만 숨기고 움직인다. 밖에서는 최종 모습.
- 곡선은 `var(--bl-ease*)`(반복은 `linear` 허용), 길이 0.15~2.4초(반복 12초까지), 색은 토큰만.
- 검사기 28번이 이 규칙을, 30번이 장마다 효과 수(등장 3종 · 반복 2종 넘으면 주의)를 본다.

## 6. 확인

- `check_live.py <결과> --shots out/` — 실패 0. 30번 주의가 뜨면 그 장의 효과를 줄이거나 반복을 한 곳으로 모은다.
- 정지 화면은 최종 모습만 보인다. 효과를 넣은 장은 브라우저에서 넘겨 보며 순서와 속도를 확인한다 —
  발표 모드(Shift+F5)에서 단계까지 밟아 본다.
