1. 시작 전 준비

의뢰서 등록에 필요한 것 — 아래 세 가지가 갖춰지지 않으면 등록 화면이 열리지 않음.

  • 사번 계정 — 사내 통합 인증(SSO)으로 접속. 별도 가입 없음
  • 고객사 코드 — 영업팀이 사전 등록. 신규 고객사는 등록에 1영업일 소요
  • 시료 수령 확인 — 시료가 접수창구에 도착한 뒤에 등록 가능
권한이 없다는 안내가 뜨는 경우 부서 이동 직후 권한 반영에 최대 1영업일 소요. 급한 건은 내선 4120 으로 임시 권한 요청.

2. 의뢰서 등록

시스템 접속 후 [의뢰 관리] > [신규 의뢰] 선택 좌측 메뉴 두 번째. 이전에 작성하던 임시저장 건이 있으면 목록 상단에 노란 띠로 표시.
고객사 코드 입력 코드 3자리를 넣으면 사명이 자동으로 채워짐. 사명이 뜨지 않으면 미등록 고객사.
시험 항목 선택 (2.1 참조) 항목별 표준 번호와 예상 소요일이 함께 표시. 여러 항목 동시 선택 가능.
시료 정보 입력 (2.2 참조) 시료 수량과 반환 여부를 반드시 지정. 미지정 시 폐기 처리.
[검토 요청] 클릭 팀장 승인 후 접수 번호가 발급되며, 이 시점부터 납기 산정 시작.

2.1 시험 항목 선택

검색창에 표준 번호 또는 항목명 입력. 고객사가 규격을 지정하지 않은 경우 — [추천] 탭에서 유사 의뢰 이력 기준 항목 확인 가능.

2.2 시료 정보 입력

시료 1건마다 한 줄. 동일 모델 여러 개는 수량으로 묶어 입력.

주의 — 접수 후 수정 불가 항목 고객사 코드와 시험 항목 — 접수 번호 발급 후 변경 불가. 잘못 등록한 건은 취소 후 재등록. 취소 이력은 고객사에 통보되므로 등록 전 확인 필수.
